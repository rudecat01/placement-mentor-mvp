Subset Sum

Given an array of non-negative integers arr[] and a value sum, determine if there is a subset of the given set with sum equal to given sum.

Example 1:

Input: arr = [3, 34, 4, 12, 5, 2], sum = 9

Output: True

Explanation: There is a subset (4, 5) with sum 9.

Example 2:

Input: arr = [3, 34, 4, 12, 5, 2], sum = 30

Output: False

Explanation: There is no subset that add up to 30.

Constraints:

  • 1 <= arr.length <= 100
  • 1 <= arr[i] <= 100
  • 1 <= sum <= 10^5
